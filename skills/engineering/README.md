# Engineering

Skills for daily code work. A **promoted** bucket — everything here ships in the plugin and is listed in the top-level [README](../../README.md).

**User-invoked**

- **[ship-issue](./ship-issue/SKILL.md)** — Run an agent on a tracker issue in its own git worktree, through five phases: context, plan, implement, verify, report.

**Model-invoked**

- **[ios-build](./ios-build/SKILL.md)** — Build the native iOS app of the project you are in and put it on the iPhone: installed directly when the phone is on the Mac's network, or as an install link over Tailscale when it is away.
